# KWAK TAEWOONG Portfolio V21

기존 콘텐츠와 이미지 경로를 유지하면서 메인 페이지의 정렬, 타이포그래피, 컬러, 카드, 타임라인과 Contact 디자인을 전면 정리한 버전입니다.

## 적용

저장소 루트에 다음 파일을 덮어씁니다.

- `index.html`
- `redesign.css`
- `script.js`
- `assets/brand/` 폴더가 없다면 함께 복사

GitHub Pages 배포 후 `Ctrl + F5`로 캐시를 새로고침합니다.
