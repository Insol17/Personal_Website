# KWAK TAEWOONG Portfolio — V20

Main-page visual redesign. Content and asset paths are unchanged.

## Install

Copy these files into the repository root and overwrite existing files:

- `index.html`
- `script.js`
- `redesign.css`
- `assets/brand/` (only when missing)

Commit and push all changed files. GitHub Pages should load `redesign.css?v=20` and `script.js?v=20`.
