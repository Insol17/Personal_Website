01 / DECKBUILDING ROGUELIKE

BENEDICT OF SINS

베네딕트 오브 신즈

PROJECT OVERVIEW

프로젝트 개요

“죄라는 것은 정말 나쁘기만 한가?”라는 질문과 아리스토텔레스의 중용에서 출발한 철학적 덱빌딩 로그라이크입니다. 총 8개 챕터에서 서로 다른 죄와 인물을 다루며, 카드 선택과 전투 규칙 자체가 각 챕터의 주제를 체험하게 만드는 것을 목표로 설계했습니다.

TYPE
개인 게임 디자인 프로젝트
ROLE
게임 기획 · 덱빌딩 시스템 · 내러티브 콘셉트
GENRE
Deckbuilding Roguelike
STRUCTURE
8개 챕터 기획
STATUS
기획 및 시스템 설계 단계
01

죄를 전투 자원으로

죄를 단순한 악성 상태가 아니라 강력하지만 대가가 따르는 플레이 자원으로 전환합니다.

02

챕터마다 다른 규칙

각 죄와 등장인물의 성격을 카드 효과와 전투 기믹으로 치환합니다.

03

선택이 메시지를 만든다

플레이어가 극단과 중용 사이의 결과를 직접 겪게 합니다.

8개의 죄, 8개의 플레이 규칙

각 챕터는 하나의 죄와 인물을 중심으로 독립적인 덱 구조와 전투 규칙을 가집니다. 챕터가 바뀔 때마다 자원을 축적하고 소비하는 방식 자체가 달라지도록 구성했습니다.

눈 먼 분노 — 분노와 과열

1챕터 ‘눈 먼 분노’는 바이킹 캐릭터의 분노, 오버히트, 잔흔 기믹을 중심으로 설계했습니다. 공격을 이어갈수록 폭발력이 높아지지만 제어를 잃을 위험도 커집니다.

철학을 설명하지 않고 플레이하게 만들기

중용을 설명문으로 전달하는 대신 과도한 선택과 지나친 억제가 각각 다른 손실을 발생시키도록 규칙에 반영합니다.

MEDIA GALLERY

스크린샷

프로젝트 화면과 핵심 시스템을 보여주는 이미지를 최대 6개까지 배치합니다.

VIDEO

플레이 영상

각 카드의 data-youtube-url에 유튜브 주소를 입력하면 영상이 표시됩니다.

MY CONTRIBUTION

담당 작업

철학적 주제를 게임 규칙으로 변환하는 데 집중했습니다. 로그라이크의 반복성과 덱빌딩의 조합 재미를 유지하면서 카드 효과와 선택 결과가 서사 메시지와 직접 연결되도록 구조를 설계했습니다.

  1. 01
    핵심 질문과 세계관 정의

    죄와 중용을 프로젝트의 중심 질문으로 설정하고 8개 챕터 구조를 구성했습니다.

  2. 02
    챕터별 시스템 기획

    각 죄의 성격을 카드 효과, 자원, 위험과 보상 구조로 치환했습니다.

  3. 03
    1챕터 전투 기믹 설계

    분노·오버히트·잔흔을 연결한 ‘눈 먼 분노’의 전투 규칙을 구체화했습니다.

  4. 04
    플레이와 서사의 연결

    선택과 덱 구성이 서사적 입장을 형성하도록 설계했습니다.

REFLECTION

철학적 메시지가 강할수록 시스템이 설명을 대신해야 한다는 점을 확인한 프로젝트입니다. 향후에는 카드 풀과 적 패턴을 실제 프로토타입으로 제작해 메시지와 전략적 재미가 동시에 성립하는지 검증해야 합니다.
