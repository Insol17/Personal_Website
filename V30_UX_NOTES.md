# V30 UX notes

## WORKS direct manipulation

The project strip is no longer a scroll container with a visible scrollbar. Pointer/touch drag directly moves the object, while the `DRAG TO EXPLORE ↔` cue makes the hidden continuation discoverable. Keyboard left/right remains available for non-pointer navigation.

Applied principles:
- direct manipulation
- affordance / signifiers
- object constancy
- Fitts's Law: the whole card remains the project target
- recognition over recall: title + genre only on the card

## Vertical project cards

Portrait 2:3 cards increase image presence and distinguish the WORKS gallery from the horizontal Hero. On wide desktop, five cards are composed as one visible set while the sixth creates a reason to drag.

## Hero → WORKS continuity

The bottom of the Hero now grades into the exact dark surface used by WORKS. This reduces the previous hard section boundary and preserves continuity from brand statement to evidence/work.

## Background

Education is treated as a separate proof block, then Project Experience reads chronologically from 2025 toward 2026. Status is a secondary attribute instead of masquerading as a date.

Applied principles:
- Gestalt proximity/common region
- chronological mental model
- progressive disclosure

## Latest Journals

The home page shows exactly three high-salience journal/news cards. The full archive remains a separate destination.

Applied principles:
- chunking
- information scent
- progressive disclosure

## Admin

The editor allows content mutation but intentionally prevents arbitrary layout mutation.

Applied principles:
- constraints
- error prevention
- separation of concerns
- immediate feedback via live preview
