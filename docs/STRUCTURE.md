# 프로젝트 구조 정리 기준

v47부터 루트 파일 수를 줄이고 역할별 디렉터리로 재배치했습니다.

v48에서는 루트에 남아 있던 과거 PATCH 문서 중복본도 제거해 `docs/patch-notes/`만 남겼습니다.

## 유지하는 원칙

1. `assets/`는 기존 경로를 최대한 유지합니다. 이미지·영상 URL 회귀를 피하기 위해 이번 구조 정리 대상에서 제외했습니다.
2. 실제 운영 콘텐츠인 `user-content/`는 패치 ZIP에 포함하지 않습니다.
3. 현재 페이지가 사용하지 않는 구버전 CSS/JS는 제거합니다.
4. 과거 수정 내역 문서는 `docs/patch-notes/`에만 보관합니다.
5. 프로젝트 상세 런타임은 `projects/runtime/`로 격리합니다.
6. HERO의 `WORLDS`는 한 파일(`scripts/hero-worlds.js`)만 소유합니다.

## 버전 레이어에 대하여

현재 `scripts/runtime/`와 `styles/runtime/`에는 v41~v45 레이어가 남아 있습니다. 이 파일들은 단순 기록용 PATCH가 아니라 현재 기능 일부가 실제로 의존하는 런타임입니다. 기능 회귀를 막기 위해 이번에는 삭제하지 않고 폴더로 격리했습니다.

향후 완전 통합 리팩터링을 할 경우 이 레이어들을 기능 단위(`portfolio`, `background`, `transition`, `mobile`)로 합치는 것이 다음 단계입니다.
