DE.CO

De.Co

PROJECT OVERVIEW

프로젝트 개요

De.Co는 타워디펜스 장르의 게임 프로젝트입니다. 현재 핵심 콘셉트와 세부 시스템을 정리 중이며, 확정된 기획과 제작 결과는 이후 이 페이지에 순차적으로 추가합니다.

TYPE
게임 디자인 프로젝트
ROLE
Game Design
GENRE
Tower Defense
STATUS
기획 정리 중
01

방어선 설계

타워의 배치와 사거리, 경로가 플레이어의 핵심 판단이 되도록 공간 규칙을 구체화할 예정입니다.

02

웨이브 대응

적 구성과 등장 순서가 동일한 정답을 반복하지 않도록 웨이브 구조를 설계할 예정입니다.

03

자원 의사결정

설치·강화·재배치 사이의 비용과 기회비용을 핵심 전략으로 검토하고 있습니다.

세부 기획 준비 중

코어 루프, 타워 역할, 적 웨이브, 자원 구조가 확정되는 순서에 맞춰 실제 기획 내용과 이미지로 교체합니다.

MEDIA GALLERY

스크린샷

프로젝트 화면과 핵심 시스템을 보여주는 이미지를 최대 6개까지 배치합니다.

VIDEO

플레이 영상

각 카드의 data-youtube-url에 유튜브 주소를 입력하면 영상이 표시됩니다.

STATUS

현재 확인된 정보는 타워디펜스 장르와 프로젝트명입니다. 확정되지 않은 설정을 임의로 채우지 않고, 실제 기획이 정리되는 대로 이 페이지를 업데이트합니다.
